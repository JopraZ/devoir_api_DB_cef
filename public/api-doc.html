Documentation de l’API

Port de plaisance de Russell

← Dashboard

Présentation générale

Cette API privée permet de gérer les réservations de catways du port de plaisance de Russell. Elle fournit des endpoints sécurisés pour l’authentification, la gestion des utilisateurs, des catways et des réservations.

Authentification

POST /api/login

Permet à un utilisateur de se connecter et d’obtenir un token JWT.

{
  "username": "admin",
  "password": "password"
  "email": "email@example.com"
}

Sécurité

Toutes les routes (sauf /api/login) nécessitent un token JWT dans le header : 

Authorization: Bearer <token>

Utilisateurs

  • GET /users – Récupérer tous les utilisateurs
  • POST /users – Créer un utilisateur
  • PUT /users/:id – Modifier un utilisateur
  • DELETE /users/:id – Supprimer un utilisateur

Catways

  • GET /catways
  • GET /catways/:catwayNumber
  • POST /catways
  • PUT /catways/:catwayNumber
  • DELETE /catways/:catwayNumber
{
  "catwayNumber": 12,
  "catwayType": "long",
  "catwayState": "bon état"
}

Réservations

  • GET /reservations
  • POST /reservations
  • PUT /reservations/:id
  • DELETE /reservations/:id
  • GET /catways/:catwayNumber/reservations
{
  "catwayNumber": 12,
  "clientName": "Jean Dupont",
  "boatName": "Céleste"
  "startDate": "2025-01-01",
  "endDate": "2025-01-10"
}

Initialisation des données

Les données sont injectées dans la base MongoDB à l’aide d’un script seed.js permettant de peupler les collections utilisateurs, catways et réservations.
